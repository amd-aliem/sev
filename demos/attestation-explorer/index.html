🔎 Attestation Report Explorer

An AMD SEV-SNP attestation report is a 1184-byte signed blob a confidential VM gets from firmware to prove what it is. Paste one below as hex or base64 and it's decoded field by field — using the exact byte layout from the sev crate.

The left column is the raw struct — every field at its byte offset. Hover a field to find its decoded card on the right; click to jump to it. Card headers collapse, and each hex block's offset chip links back to the struct.

A real SEV-SNP report loads by default (chip ID, report ID & report data replaced with abcd… placeholders). Everything runs in your browser — nothing is uploaded.
